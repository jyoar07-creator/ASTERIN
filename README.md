## 📚 About This Repository
I created this space to track my progress as I learn C programming. It acts as a central hub for all my source code, compiled executables, and course-related experiments.

## 🗂️ Current Contents
* **`TempCalc.c`**: A functional C program designed to convert temperatures between Celsius and Fahrenheit.
* **`TempCalc.exe`**: The compiled Windows executable for the temperature calculator.

## 🚀 How to Compile and Run
To run the C files on your local machine, you will need a C compiler such as GCC.
1. Clone this repository to your local machine.
2. Open your terminal or command prompt.
3. Compile the code using: `gcc filename.c -o outputname`
4. Run the executable: `./outputname` (or `outputname.exe` on Windows).
